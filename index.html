À savoir avant de commencer

Before you start

  • Il faut Chrome ou Edge sur ordinateur.
  • Si la carte n'apparaît pas, maintiens BOOT en la branchant.
  • L'installation efface l'historique des messages. Les réglages restent, sauf si tu coches « Erase device », à réserver à une première installation.
  • Pour mettre à jour un Hub déjà installé sans rien perdre, passe plutôt par l'appli : Réglages → Mise à jour, avec les fichiers de la dernière version.
  • Le module MeshCore doit avoir le firmware Companion : flasher.meshcore.co.uk.
  • You need Chrome or Edge on a computer.
  • If the board does not show up, hold BOOT while plugging it in.
  • Installing erases the message history. Settings are kept unless you tick "Erase device", meant for a first install.
  • To update an installed Hub without losing anything, use its app instead: Settings → Update, with the files of the latest release.
  • The MeshCore radio needs the Companion firmware: flasher.meshcore.co.uk.
